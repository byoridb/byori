# 작업 절차와 검증

macOS 앱에서 작업이나 세션을 선택하고 툴바의 **작업 절차·검증**을 누르세요.
터미널 위 작업 헤더에서도 열 수 있습니다. 화면을 연 시점의 작업과 체크아웃을 유지합니다.

## 작업 절차

새 작업을 만들 때 **버그 수정**, **기능 추가**, **코드 리뷰** 프리셋을 선택하거나,
기존 작업의 절차 탭에서 적용하세요. 목표·완료 조건·메모를 편집하고 직접 확인한 단계에
표시한 뒤 저장합니다. 기존 절차를 바꾸면 확인을 거칩니다.

단계 체크는 사용자가 기록한 진행 상태이며 테스트 실행이나 작업 완료를 뜻하지 않습니다.
인계문 복사는 현재 초안과 마지막으로 확인한 검증 상태를 담습니다. 복사해도 에이전트에
전송하거나 터미널에서 실행하지 않습니다. 기존 작업에 새 세션을 열어도 절차는 유지됩니다.

## 검증 명령

검증 탭의 명령 편집에서 Python(`python3 -m pytest`), Swift(`swift test`),
Node.js(`npm test`), Rust(`cargo test`) 예시를 추가하거나 직접 입력하세요.
프로젝트의 실제 실행 방식에 맞게 편집해야 하며 테스트 도구를 자동 추정하지 않습니다.

명령은 프로젝트의 모든 작업에서 공유합니다. 이름·실행 파일·인수·제한 시간(1~1,800초)·
필수 여부를 설정하고 최대 12개까지 저장할 수 있습니다. 인수는 한 줄에 하나씩 입력하며
빈 줄은 제외합니다. 표시된 체크아웃에서 실행 파일과 인수 배열을 직접 실행합니다.
인수의 따옴표·파이프·셸 치환은 문자 그대로 전달됩니다. 셸이 필요하면 실행 파일로
셸을 명시적으로 선택해야 합니다.

저장은 실행을 시작하지 않습니다. 저장한 명령의 **실행**을 누르세요. 미저장 편집 중에는
실행할 수 없습니다. **취소**는 관리 중인 프로세스 그룹을 중지하고 취소 기록을 남깁니다.
체크아웃당 검증 하나가 실행되며, 실행 중 작업·프로젝트·체크아웃 제거와 해당 브랜치 전환을
막습니다. 앱 종료 시 검증을 취소하고 정리를 기다립니다. 검증 명령은 터미널에서 실행할
때처럼 프로젝트 코드를 실행하거나 파일을 변경할 수 있습니다.

## 통과 표시의 의미

실행 기록은 명령·실제 실행 파일·종료 코드·시각·제한된 출력과 실행 전후의 코드 지문을
저장합니다. 화면을 열거나 상태를 새로 고치면 현재 지문과 대조합니다. 파일을 실시간
감시하는 기능은 아니므로 수정 후에는 새로 고침이 필요하며, 마지막 확인 시각을 표시합니다.

마지막 실행이 성공했고 저장한 명령이 같으며 실행 전·후·조회 시점의 지문이 모두 완전하고
일치할 때만 현재 **통과**입니다. HEAD, 스테이징 인덱스, 추적 파일과 Git이 무시하지 않는
파일의 종류·내용을 언어와 형식에 관계없이 확인합니다. 같은 커밋의 이미 수정된 파일을
다시 고쳐도 이전 결과를 무효화합니다. 실행 중 변경, 명령 변경, 취소, 시간 초과, 비정상 중단은
현재 통과로 표시하지 않습니다. 필수 명령이 없으면 **검증 미설정**입니다.

지문 조회 한도는 파일 20,000개·전체 128 MiB·파일당 16 MiB·Git 목록 응답당 256 KiB·
스캔 예산 10초입니다. 링크·서브모듈·미지원 파일·잘리거나 읽지 못한 목록·조회 중 변경·
한도 초과는 **코드 상태 미확인**으로 남깁니다. Git이 무시한 파일, 외부 의존성, 도구 버전,
환경 변수와 원격 서비스는 확인 범위 밖입니다. 통과는 기록된 검증과 관측한 입력에 대한
결과이며 모든 요구사항 충족을 보장하거나 작업을 자동 완료하지 않습니다.

## 저장과 복구

- 프로젝트 명령: `~/.byori/verification-profiles/<project-id>.json`
- 작업 절차: `~/.byori/tasks/<task-id>/workflow.json`
- 검증 기록: `~/.byori/tasks/<task-id>/verification.json`

최근 30건을 보관하며 기록당 출력은 최대 64 KiB와 잘림 표시를 저장합니다. ByoriDB 상태와
독립적인 로컬 비공개 파일이고, 작업을 보관하면 함께 이동합니다. 원문 출력은 ByoriDB에
저장하지 않습니다. 에이전트와 공유할 중요한 결과는 기존 체크포인트 기능에 요약해 남기세요.
앱 재시작 후 미완료 기록은 중단됨으로 표시하며 성공으로 간주하지 않습니다.

이번 범위는 네이티브 작업 절차와 검증 이력입니다. 자동 작업 에이전트, 학습된 스킬,
CLI/MCP 전체에 적용하는 완료 차단 기능은 포함하지 않습니다.
